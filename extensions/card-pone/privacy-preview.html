운영자와 문의 메일 보관 기준은 확정했습니다. 접속 로그 보관 설정 확인과 시행일 확정 전이므로, 아직 시행 중인 개인정보처리방침이 아닙니다.

화면 캡처와 카드 분석

스캔을 실행하고 영역을 선택하면 현재 탭의 보이는 화면 전체가 일시적으로 캡처됩니다. 선택한 부분을 잘라 기기 안에서 이미지와 카드번호를 분석합니다. 잘라내기 전의 화면도 일시적으로 메모리에서 처리됩니다.

캡처 이미지와 OCR 텍스트를 서버에 업로드하거나 파일로 저장하지 않습니다. 방문 기록 전체를 조회하지 않습니다. 현재 탭 주소는 지원 페이지와 페이지 변경 확인에만 사용하며 서버에 보내지 않습니다.

외부 서버 요청

  • 카드 비교 자료를 Card Pone 서버에서 내려받으며 요청 경로에 카드번호와 언어가 포함될 수 있습니다.
  • 시세 조회에는 상품 ID가 포함됩니다. 비교 자료·시세 요청에는 홈페이지 로그인 쿠키와 referrer를 보내지 않습니다.
  • 결과 썸네일은 Card Pone 및 상품 이미지 제공 서버에서 불러옵니다. referrer는 보내지 않습니다.
  • 서버와 CDN은 요청 처리에 필요한 IP 주소, 요청 시각·경로 등을 처리할 수 있습니다. 실제 접속 로그 보관 기준은 확인 후 확정합니다.

기기 내 저장

공개 카드 비교 자료를 브라우저 캐시에 저장합니다. 사용자 캡처 사진은 저장하지 않습니다. 자료 갱신 시 오래된 자료를 정리하며 브라우저의 확장프로그램 데이터 삭제 또는 제거로 정리할 수 있습니다.
