## 상세 소개

웹페이지에서 궁금한 원피스 카드의 영역을 선택하면 Card Pone Scan이 이미지와 카드번호를 비교해 카드 후보를 보여줍니다.

- JP·EN 카드 후보와 판본 확인
- 거래 기록이 있는 상품의 Single·PSA10 시세를 원화로 표시
- 카드 도감 또는 검색, 차트와 거래 내역으로 이동
- 여러 판본이 후보로 남으면 사용자가 확인한 뒤 시세 표시
- 인식 오류 문의 메일 작성

시세는 최근 거래일 중앙값이며 판매 중 최저가나 구매 가능 가격을 의미하지 않습니다. 원화 금액은 표시된 환산 기준을 적용한 참고값입니다. 수수료·배송비는 포함하지 않으며, 거래 기록이 없는 경우 시세가 표시되지 않습니다.

인식 결과는 사진 품질, 반사, 가림, 언어 및 판본에 따라 다를 수 있습니다. 카드번호가 같아도 판본과 이미지를 확인해 주세요. PSA 카드는 케이스 전체보다 내부 카드 영역을 선택하는 것이 좋습니다. Chrome 내부 페이지 등 캡처가 제한되는 화면에서는 작동하지 않습니다.

캡처 이미지는 기기에서 분석하며 서버에 업로드하지 않습니다. 카드 비교 자료와 시세를 가져오기 위해 카드번호·언어·상품 ID를 포함한 요청이 발생할 수 있습니다. Card Pone 홈페이지 회원만 이용할 수 있습니다. 확장의 로그인 버튼으로 연 홈페이지 탭에서 로그인한 뒤 연결 확인을 누르세요. 사용 중 연결용 탭을 열어 두어야 합니다.

회원 확인 시 전용 홈페이지 탭의 현재 액세스 토큰을 Card Pone 인증 API로 전송하고 서버가 Supabase에서 확인합니다. 확장은 비밀번호·갱신 토큰을 별도로 저장하지 않으며 액세스 토큰을 디스크에 저장하지 않습니다. 웹스토어 제출 시 인증 정보 처리와 변경된 권한을 신고해야 합니다.

Card Pone은 독립적인 서비스이며, 카드 권리자 또는 시세 제공처의 공식 확장프로그램을 의미하지 않습니다.

## 단일 목적

사용자가 선택한 원피스 카드 이미지를 식별하고 해당 카드의 참고 시세와 도감 정보를 제공하는 것.

## 권한 설명

- activeTab: 사용자가 툴바 아이콘을 눌러 허용한 현재 탭의 화면을 스캔합니다. 상시 전체 사이트 접근이나 방문 기록 수집을 위한 권한이 아닙니다.
- scripting: 현재 탭에 영역 선택 UI를 삽입하고 화면 크기를 확인합니다.
- sidePanel: 스캔 명령과 카드 인식 결과 및 참고 시세를 표시합니다.
- storage: 연결용 홈페이지 탭의 ID만 브라우저 세션 메모리에 저장합니다.
- www.optcgkorea.com: 공개 카드 비교 자료 및 시세 API를 요청합니다.

## 원격 코드

실행 코드는 패키지 안에 포함됩니다. OCR 모델과 OpenCV/WASM도 로컬 패키지입니다. 내려받는 JSON은 카드 비교 자료이며 실행하지 않습니다. 원격 이미지 로딩은 결과 썸네일 표시용입니다.

## 개인정보 신고 검토표

신고 화면의 최신 정의에 맞춰 확인해야 하며 모든 항목을 '수집 없음'으로 일괄 선택하지 않습니다.

- 웹사이트 콘텐츠: 보이는 화면 전체를 일시 캡처하고 선택 영역을 로컬 분석함. 이미지 업로드 및 영구 저장 없음.
- 웹 탐색 활동: 현재 탭 URL을 지원 여부·탭 변경 검증에 로컬 사용. 방문 기록 목록 수집이나 URL 전송 없음.
- 문의: 사용자가 전송할 때 발신 이메일과 작성 내용이 전달됨. 문의 완료 후 90일 이내 삭제.
- 인증 정보: 전용 홈페이지 탭의 액세스 토큰을 회원 확인 요청에 사용하며, 응답의 회원 ID는 연결 및 계정 변경 확인에만 사용. 확장에 영구 저장하지 않음.
- 네트워크: 카드번호·언어·상품 ID 요청 및 서버/CDN 접속 메타데이터 처리. 개인정보처리방침 참고.
- 판매·광고 목적 이용: 하지 않음. 단일 목적 외 사용하지 않음.

## 심사자 확인 절차

1. 일반 HTTPS 카드 이미지 페이지를 엽니다. Chrome 내부 화면은 지원하지 않습니다.
2. 툴바의 Card Pone Scan 아이콘을 누릅니다. Card Pone 로그인 버튼으로 열린 전용 탭에서 홈페이지 회원으로 로그인하고, 패널에서 연결 확인을 누릅니다. 연결 탭은 열어 둔 채 카드 이미지 페이지로 돌아와 툴바 아이콘을 다시 누르고 스캔을 선택합니다.
3. 카드 영역을 드래그합니다. 취소 또는 Escape는 캡처 없이 종료합니다.
4. 후보 이미지·번호·언어를 확인합니다. 필요한 경우 '이 카드로 시세 확인'을 선택합니다.
5. 참고 시세, 거래일, 원화 환산 기준과 도감·차트 링크를 확인합니다.
6. 홈페이지 회원 로그인이 필요하며 유료 계정은 필요하지 않습니다. 회원 확인·시세·최신 비교 자료를 위해 서버 연결이 필요합니다. 심사용 계정 안내는 제출 콘솔의 비공개 영역으로 제공하고 공개 저장소에 계정 정보를 넣지 않습니다.

## 공개 전에 남는 승인

- 개발자 계정 등록, 약관 동의 및 등록비 결제가 필요한 경우 운영자 직접 처리.
- 카드 이미지·상표 사용 권한 검토. 기술적 다운로드 가능 여부는 이용 허락을 의미하지 않음.
- 문의 메일 90일 이내 실제 삭제 절차 운영.
- 실 Chrome에서 제출 ZIP 설치 및 권한 승인·최종 수동 검증.
- 제출 및 자동 공개 옵션은 운영자 확인 후 실행. 이 문서는 심사 승인 보장이 아님.
