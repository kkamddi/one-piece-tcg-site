# Card Pone Scan 개인정보 안내 초안

검토 대상: 확장프로그램 0.1.10. 아직 공개된 개인정보처리방침이 아닙니다.

운영자: Card Pone. 문의처: optkr26@gmail.com. 문의 메일은 처리 완료 후 90일 이내 삭제하는 기준으로 운영자 확인을 받았습니다. 자동 삭제 기능이 설정되었다는 뜻은 아닙니다.

## 화면과 이미지 처리

사용자가 스캔을 시작하고 영역을 선택하면 현재 탭의 보이는 화면이 일시적으로 캡처됩니다. 선택 영역을 잘라 기기에서 카드번호와 이미지를 분석합니다. 따라서 선택 영역뿐 아니라 보이는 화면 전체가 잘라내기 전에 일시적으로 메모리에서 처리됩니다.

확장프로그램은 캡처 이미지와 OCR 텍스트를 서버에 업로드하거나 파일로 저장하지 않습니다. 방문 기록 전체를 조회하지 않습니다. 현재 탭 주소는 지원 페이지 확인 및 스캔 도중 페이지 변경 확인에 사용하며 서버로 보내지 않습니다.

## 네트워크 요청

- Card Pone 서버에서 카드 비교용 자료를 내려받습니다. 요청 경로에 카드번호와 언어가 포함될 수 있습니다.
- 시세 조회 요청에는 선택된 상품 ID가 포함됩니다. 해당 요청과 비교 자료 요청에는 홈페이지 로그인 쿠키와 페이지 referrer를 보내지 않습니다.
- 결과 카드 이미지는 Card Pone 이미지 서버 및 상품 이미지 제공 서버에서 불러옵니다. 결과 이미지 요청에는 no-referrer가 적용됩니다.
- 서버/CDN은 요청 처리 과정에서 IP 주소, 요청 시각, 요청 경로 등 통상적인 접속 정보를 처리할 수 있습니다. 운영 로그의 실제 보관 기간과 접근 권한은 공개 전에 별도 확인해야 합니다.

## 기기 내 저장

카드 비교 자료는 재사용을 위해 브라우저 Cache Storage에 저장합니다. 이는 사용자 캡처 사진이 아닌 공개 카드 자료입니다. 자료 갱신 시 이전 버전 자료를 정리합니다. 브라우저에서 확장프로그램 데이터 삭제 또는 제거로 정리할 수 있습니다.

## 문의와 외부 링크

문의하기는 optkr26@gmail.com으로 보낼 메일 초안을 엽니다. 버전과 최대 3개 후보의 카드번호·언어가 입력되며 이미지와 방문 페이지 주소는 첨부하지 않습니다. 사용자가 메일 앱에서 전송해야 접수됩니다. 발신 주소와 사용자가 작성한 내용은 문의 처리에 사용하며, 처리 완료 후 90일 이내 삭제합니다. 개인정보 열람·삭제 요청도 같은 주소로 접수합니다. 메일 앱이 설정되지 않은 환경에서는 위 주소로 직접 연락할 수 있습니다.

도감·시세 링크를 클릭하면 홈페이지를 새 탭으로 엽니다. 홈페이지 이용에는 홈페이지의 개인정보처리방침이 별도로 적용됩니다.
