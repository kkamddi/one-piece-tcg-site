# 수집 가이드 카드 대조 목록

기준: 2026-09-03

## 연결 완료

- 일본판 시리즈별 망가 카드 39종
- 챔피언십 카드 67건: 일본판 42건, 한국판 25건
- 플래그십 카드 30건: 일본판만 수록
- 프로모 카드 106건: 일본판 부록·응모·매거진·가이드·기타 특전
- 일반 카드는 `src/data/cards.json`, 별도 대회 특전은 `src/data/special-promo-cards.js`의 `cardId`와 연결
- 대회 특전 이미지는 확인된 공식 사이트 또는 정확한 SNKRDUNK 상품 이미지를 로컬 에셋으로 사용

## 확인이 필요한 이유

아래 카드들은 캐릭터나 일련번호 후보는 도감에 있지만, 도감 데이터에 대회명·입상·배포처 필드가 없다. 같은 카드번호의 패럴렐이 여러 종이므로 Card Pone 상세 URL이나 정확한 `cardId`가 필요하다.

## 챔피언십 추가 확인 필요

일본판에서 현재 도감에 정확한 대회 버전이 없거나 시리얼별 이미지가 구분되지 않는 항목:

- 2022 본선 루피 시리얼별 우승·준우승 구분
- 2023 일본 제일 결정전 샹크스는 공통 시리얼 이미지 1종만 연결했으며 우승·준우승 번호별 이미지 확인 필요

한국판 2026-27 Wave 1은 공식 한글판 카드 리스트의 이미지를 사용했다. 현재 정확한 SNKRDUNK 상품이 없으므로 일반판 시세에 연결하지 않고 `시세 준비 중`으로 표시한다.

참고 이미지의 `미공개` 영역은 등록 대상에서 제외한다.

## 플래그십 추가 확인 필요

- 현재 참고 이미지에 공개된 일본판 우승·TOP 8 카드는 모두 연결 완료
- 한글판 플래그십 항목은 가이드 범위에서 제외

## 프로모

V JUMP·최강점프·주간 소년 점프의 부록과 응모, JUMP GIGA, ONE PIECE 매거진, 컴플리트 가이드, 공부 다메 점프, 원피스 학원, The Choppers, DVD 특전, FILM RED 관련 카드를 연결했다. 챔피언십 특전은 챔피언십 가이드와 중복되어 프로모 가이드에서 제외했다.

PSA Magazine과 이후 공개되는 기타 특전은 정확한 카드번호와 이미지가 확인되는 순서대로 추가한다.

## 추가 정보 받는 형식

각 항목마다 다음 중 하나만 있으면 연결할 수 있다.

1. Card Pone 카드 상세 URL (`/cards/jp/...` 또는 `/cards/kr/...`)
2. Card Pone `cardId` (`JP::...` 또는 `KR::...`)
3. 도감에 없는 카드는 정확한 카드번호와 이미지
