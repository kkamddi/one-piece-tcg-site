Card Pone Scan 개인정보처리방침

시행일: 2026년 9월 24일

회원 로그인 연결 (0.1.16부터)

Card Pone 홈페이지 회원만 확장 기능을 이용할 수 있습니다. 확장의 로그인 버튼으로 연 전용 홈페이지 탭에서 로그인한 뒤 연결 확인을 누르세요. 사용 중 연결용 탭을 열어 두어야 합니다.

확장은 해당 탭의 현재 액세스 토큰을 읽어 HTTPS로 Card Pone 회원 확인 API에 전송하며, 서버가 기존 Supabase 인증 서비스에서 유효한 회원인지 확인합니다. 회원 ID는 현재 연결 및 계정 변경 확인에만 사용합니다. 비밀번호와 갱신 토큰은 확장에서 별도로 저장하거나 서버로 전송하지 않습니다. 액세스 토큰은 요청 처리 중 메모리에서만 사용하고 로그·URL·파일에 기록하지 않습니다. 연결 탭 ID만 브라우저 세션 메모리에 보관합니다.

연결용 탭을 닫거나 로그아웃하면 다음 인증 확인에서 기능을 차단합니다. 패널은 30초 간격 및 포커스 복귀 시 확인하고, 스캔과 시세 요청 전후에도 확인합니다. 오프라인이나 인증 확인 실패 시에는 사용을 허용하지 않습니다. 다른 기존 탭의 로그인 정보를 찾아 읽지 않습니다.

화면 캡처와 카드 분석

스캔을 실행하고 영역을 선택하면 현재 탭의 보이는 화면 전체가 일시적으로 캡처됩니다. 선택한 부분을 잘라 기기 안에서 이미지와 카드번호를 분석합니다. 잘라내기 전의 화면도 일시적으로 메모리에서 처리됩니다.

캡처 이미지와 OCR 텍스트를 서버에 업로드하거나 파일로 저장하지 않습니다. 방문 기록 전체를 조회하지 않습니다. 현재 탭 주소는 지원 페이지와 페이지 변경 확인에만 사용하며 서버에 보내지 않습니다.

외부 서버 요청

  • 카드 비교 자료를 Card Pone 서버에서 내려받으며 요청 경로에 카드번호와 언어가 포함될 수 있습니다.
  • 시세 조회에는 상품 ID가 포함됩니다. 비교 자료·시세 요청에는 홈페이지 로그인 쿠키와 referrer를 보내지 않습니다.
  • 결과 썸네일은 Card Pone 및 SNKRDUNK 등 상품 이미지 제공 서버에서 불러옵니다. referrer는 보내지 않습니다.
  • 요청을 받는 서버와 CDN은 전송·보안 처리를 위해 IP 주소, 요청 시각·경로 등 접속 정보를 처리할 수 있습니다.

서버 로그와 보관

2026년 9월 24일 확인 기준, 운영 Cloudflare 계정에 Logpush 전송 작업이 없고 Log Explorer 저장 기능은 구독하지 않았습니다. Pages Functions 실시간 로그는 Cloudflare 문서상 저장되지 않습니다.

이는 Cloudflare의 보안·분석 자료까지 존재하지 않는다는 뜻은 아닙니다. 현재 도메인 Free 플랜의 보안 이벤트 조회 범위는 최대 최근 24시간, Security Analytics의 이력 범위는 최대 최근 7일입니다. 이는 해당 기능의 조회·보관 범위이며, Cloudflare의 모든 내부 데이터가 그 시점에 삭제된다는 보장은 아닙니다. 서비스 제공자의 별도 처리에는 해당 제공자의 정책이 적용됩니다.

정보 이용 제한

Card Pone Scan은 Chrome Web Store User Data Policy의 Limited Use 요건을 준수하며, Chrome API를 통해 접근한 정보를 사용자 요청에 따른 카드 인식과 결과 제공에만 사용합니다.

캡처 정보와 인식 결과를 판매하거나 맞춤 광고에 사용하지 않습니다. 처리 방식이 바뀌면 이 페이지에 변경 사항과 시행일을 안내합니다.
